# 开源发布审查记录（2026-10-18）

本记录区分已完成的静态审查、构建验证与仍需发布者处理的事项，不代表法律意见或全部设备认证。

## 素材与许可证

- 默认角色仅保留本项目原创 ChargeBot、ChargeCat；旧角色与测试素材移至本地忽略目录，不进入新源码导出或安装包。
- 本项目自有代码与原创素材采用根目录 MIT 许可；第三方库保持各自许可证，不能将整个依赖集合视为 MIT。
- Spine 运行库随源码及构建保留版权声明、原许可证与当前完整协议。采用要求每位用户持有有效 Spine Editor 许可的分发条件，首次运行需用户主动声明；声明本身不会授予许可或验证购买记录。
- Live2D 保留功能及本地运行库准备流程。Core 不进入源码导出；当前开发包集成的运行库不代表已获公开发布许可。公开 Release 构建默认受发布确认检查约束，必须先完成适用许可手续。
- README 提供用户自行导入步骤及资源平台链接；平台收录不代表可重新分发其中模型。

## 系统与导入安全

- 未发现应用代码执行系统 shell、root 操作、写入系统安全设置、静默安装或关闭锁屏安全验证的路径。
- 应用不申请 INTERNET、广泛存储管理、静默安装、系统设置写入权限。导入采用系统选择器的 content URI；分享仅暴露指定导出缓存。
- 模型 ZIP 限制条目数量、解压尺寸、单文件尺寸、JSON 深度和纹理像素总量，并拒绝路径穿越及导入脚本。用户 HTML/JS/SVG 不作为模型执行。
- WebView 使用受控本地资源来源，关闭文件/内容/网络访问以及多窗口等无关能力。内置 SVG 为项目自有静态图形。
- 音频频谱仍需用户主动授予所需权限；充电通知描述为“充电自动显示已开启”，不使用含混的“监听中”。

## 功能与设备适配

- 新安装默认无线充电触发；有线充电开关默认关闭。自动显示总开关仍由用户启用，既有用户明确保存的设置予以保留。
- 全屏支持左右滑动轮换角色并保存选择；竖直上滑退出与返回键、关闭按钮等价，操作提示中明确写出；时钟、角色与系统安全区域适配保持独立。
- 完善小屏选择界面、横竖屏断点、刘海/导航区域和常见品牌权限引导。已用 Xiaomi 14 验证过主要界面；其他品牌仍需按 ANDROID_COMPATIBILITY.md 实机验证，后台限制不能保证绕过。
- Android 单元测试、JavaScript 布局/帧循环测试和 Lint 用于回归检查。Lint 仍存在既有警告，不应解释为没有风险。

## 发布前待办

1. 完成 Live2D 适用发布许可；仅在真实取得相应授权后确认 Release 发布参数。
2. 用多品牌设备完成充电、锁屏、后台、比例和音频回归；当前不能宣称所有品牌均已实测。
3. 旧 Git 提交历史包含已移除素材。工作区删除不能清除历史；使用 tools/export_public_source.py 生成的不含 Git 历史的源码包创建干净仓库，或另行审查并清理完整历史。当前没有执行远程历史改写。
4. 逐项复核拟发布 APK、用户导入说明、第三方声明和最终仓库内容。静态扫描无法证明不存在所有侵权、安全漏洞或厂商兼容问题。
