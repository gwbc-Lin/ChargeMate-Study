# Android 品牌与屏幕适配

本项目支持 Android 10 / API 29 及以上的 Android APK 环境。除小米 14 外，以下品牌仅完成代码检查与入口回退设计，**没有据此宣布真机兼容认证**。系统菜单名称随地区和 ROM 更新变化，打开设置不等于已获得权限。

| 品牌 / 系统 | 已有适配与检查路径 | 验证程度 |
| --- | --- | --- |
| 小米 / Redmi / POCO，MIUI / HyperOS | 自启动、应用管理中的其他权限（后台弹出/锁屏显示）、电池后台限制；失败回退应用详情 | 小米 14 / Android 16 / HyperOS 3 有真机记录；其他机型待验证 |
| OPPO / realme，ColorOS | 兼容 ColorOS / OPlus 入口，应用耗电管理中的自启动、后台活动 | 代码检查，真机待验证 |
| OnePlus，OxygenOS / ColorOS | 与 OPlus 入口兼容，失败回退系统应用详情 | 代码检查，真机待验证 |
| vivo / iQOO，OriginOS / FuntouchOS | 后台启动 / 自启动入口；失败展示手动路径 | 代码检查，真机待验证 |
| HONOR，MagicOS | 应用启动管理，手动管理后台限制 | 代码检查，真机待验证 |
| HUAWEI，EMUI / 能运行 APK 的系统 | 应用启动管理；仅在确实支持 Android APK 的环境内适用 | 代码检查，真机待验证；不承诺原生鸿蒙兼容 |
| Samsung，One UI | 应用电池设置，检查休眠 / 深度休眠名单；通用应用详情入口 | 手动指引与回退，真机待验证 |
| Google Pixel / 类原生 Android | 应用电池用量、允许后台使用、通知及可选悬浮窗设置 | 通用系统入口，真机待验证 |

不能运行 Android APK 的设备不通过“调整权限”变得兼容。没有无线充电硬件的手机仍可手动显示；系统未提供屏保设置入口时，不把屏保列为已验证能力。

## 权限与系统行为

- 通知权限仅在需要时请求，拒绝时不伪装为通知可用。
- 读取无线电源不等于后台弹出、锁屏显示或息屏亮屏都可用，各项单独判断。
- 厂商独立 Activity 无公开稳定接口，采用可处理性检查、异常回退和手动路径。三星和 Pixel 未检测到厂商页面时显示“说明”，不错误标成权限缺失。
- 电池优化入口使用系统设置列表，不直接申请未声明的豁免权限。
- 悬浮窗授权可作为部分后台启动条件，但不等于系统必然放行。本应用不绘制常驻悬浮窗，也不通过无障碍、root 或反复拉起来绕过系统限制。
- ForegroundService、锁屏与 PendingIntent 均受 OS 限制。参考 [Android 后台 Activity 安全规则](https://developer.android.com/guide/components/activities/secure-bal)、[前台服务说明](https://developer.android.com/develop/background-work/services/fgs)。
- 三星休眠行为参考 [Samsung 官方应用管理](https://developer.samsung.com/mobile/app-management.html)，避免把一般指引描述为本项目已经在所有 One UI 机型实测。

## 屏幕与字体

- 主界面使用 dp / sp、系统安全区域与可滚动容器；角色库在可用宽度达到 640dp 且高度达到 320dp 时采用双栏，其余采用上下排列。分类筛选允许换行。
- 角色、时钟与频谱按完整窗口铺满并居中，不再扣除摄像头一侧的整条区域。展示 Activity 和系统屏保显式允许延伸至显示切口区域；仅电量文字、原生名称、关闭按钮应用安全边距。物理摄像头开孔本身无法显示像素。
- 关闭按钮至少 48dp 高，长角色名称单行省略，降低不同像素密度和字体设置造成的碰撞。
- 横竖屏角色位置按可用尺寸和素材边界计算，不使用小米 14 的固定像素位置。半身构图允许角色遮挡部分时钟，不代表所有模型都能自动识别人脸或腰线。
- 现有 JS 用例覆盖 320×568、393×852、600×960、800×1280 竖屏，以及 1280×720、2340×1080、1024×768、640×360 横屏的几何边界。它们是布局计算测试，不等同于这些尺寸对应设备的完整截图验收。

## 仍需在其他品牌执行的验收

每个实际目标机型记录品牌、ROM、Android/WebView 版本、分辨率、密度、字体大小及结果，不仅写“Android 可用”：

1. 首次通知拒绝与重新授权；Spine 许可未确认时不能进入运行功能。
2. 授权后息屏/亮屏、锁屏、正在使用其他应用、通知点击、手动预览与屏保（如果可用）。
3. 无线连接防抖、满电/充电保护暂停、稳定断开、短时线圈偏移。
4. 最近任务移除、系统回收、重启后的恢复提示；强行停止不保证自动恢复。
5. 普通屏、挖孔/刘海、手势导航/三键导航、横竖屏、平板/折叠窗口、150% / 200% 字体。
6. PNG、获授权的 Live2D 和 Spine 用户模型；不同 GPU 与 Android System WebView；音频频谱在本机是否有真实系统输出。

目前无法在没有这些真机的情况下完成上述全量验收，发布说明应持续保留这一状态。
