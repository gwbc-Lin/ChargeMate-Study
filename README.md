# ChargeMate

Android 无线充电宠物与时钟：连上无线充电器时全屏显示原创角色和走时时钟，稳定断开后退出。离线运行，无账号、无广告、不申请网络权限。

当前版本 **0.8.0**，Android 10（API 29）及以上。

> **本项目仅用于学习。** 用于学习 Android 开发（Compose、前台服务、充电会话状态机、WebView 离线渲染等），不是可商用的产品，也不授予任何第三方素材、运行库、角色或商标的使用权。请勿用于商业发布、应用商店上架或二次分发；学习目的不能替代许可。

## 功能

- 无线充电触发全屏展示，有线充电可选开启；稳定断开后退出，同一会话不反复弹出。
- 原创角色：充电机器人、充电猫（SVG，项目 MIT 许可）。
- 支持导入自己的 PNG 立绘或 Spine 模型（模型与运行库授权需自备）。
- 大数字时钟、横竖屏布局、电量提示。
- 点击互动、左右滑动切换角色、上滑或返回退出。
- 立即展示（前台服务）与系统屏保两种模式；按温度降载，支持充满、超时退出。

## 不包含什么

- 不附带任何游戏或动漫角色模型，默认角色为原创 SVG。
- Spine 模型由使用者自行导入；仓库只自带 Spine 运行库，不含模型文件。

## 构建

需要 JDK、Android SDK 与仓库自带的 Gradle Wrapper；在本机 `local.properties` 写入 `sdk.dir`（不要提交该文件）。

```powershell
.\gradlew.bat :app:assembleDebug
```

默认启用 Spine 导入（`pixi7.min.js` / `pixi-spine.js` 随仓库提供），无需额外文件；没有 Spine 许可时可用 `-PspineEnabled=false` 关闭。

## 导入自己的角色

**PNG**：首页「导入素材 → 选择 PNG 文件」→ 角色库预览 → 使用此角色 → 「调整图片位置与大小」分别保存横竖屏构图。上限 32 MiB、任一边 8192 px。

**Spine**：一个 ZIP 只放一个模型（`.skel` 或骨骼 JSON + `.atlas` + 全部贴图，同目录、文件名大小写一致），支持 3.7–4.1；导入后同样在角色库启用。

模型与素材的授权需自行确认；应用只在本机保存导入副本，不上传、不分享。
